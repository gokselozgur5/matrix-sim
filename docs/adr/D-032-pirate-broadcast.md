# D-032 — Zion fleet and the pirate broadcast jack-in path

*In the context of Zion becoming a real system with a city and a fleet, facing the fact that rebels enter the Matrix without pods, we lean toward a second link kind — NeuralLink(PIRATE) opened by a hovercraft BroadcastRig with range, capacity and traceability — and against a cosmetic Zion, to achieve free drama from honest mechanics, accepting a Zion-side subsystem to build and balance.*

## Context and Problem Statement

Today every link is a pod hardline. In the fiction, Zion crews jack in over pirate broadcast: a hovercraft parks in range, an operator opens channels, agents hunt the intruders, and leaving cleanly requires a phone line. If Zion joins the universe (D-031), its defining verb is broadcasting into enemy territory.

## Decision Drivers

* The Matrix must not know link kinds apart (A1: avatars are avatars)
* Opt-out humans (D-011) need a destination with purpose — Zion's population registry
* Mechanics should generate story pressure without scripting (agents converge on pirates)
* Rig budgets give the fleet real operational decisions (who is in, for how long)

## Considered Options

* Full mechanics: BroadcastRig with range/signal budget, PIRATE links, phone-line exits, agent trace pressure
* Cosmetic Zion: population registry only, no fleet operations
* Zion as pure log flavor (status quo of the draft)

## Decision Outcome

Proposed option: "full mechanics", because a rig with a budget and a trace risk produces missions, retreats and losses out of arithmetic — the drama arrives free, exactly the repo's thesis. Final call in thread #95 (v4.0 gate).

### Consequences

* Good, because the treaty's liberated humans stop being a log line and start being Zion's growth curve
* Good, because two link kinds exercise D-013's bridge design without touching the Matrix side
* Bad, because balance knobs (range, capacity, trace rate) join the D-006 tuning family

### Confirmation

A v4.0 run shows: broadcast mission opens N PIRATE links; agent convergence pressure measurably higher near pirate avatars (METRIC); unclean disconnect (rig destroyed mid-session) triggers the death rule through the same bridge; Zion census rises after a treaty.

## Pros and Cons of the Options

### Full mechanics

* Good, because fleet operations become emergent gameplay for the Director
* Good, because the Matrix side ships zero new code (the boundary holds)
* Neutral, because mission scheduling adds Director complexity at v4.0
* Bad, because more tuning surface

### Cosmetic Zion

* Good, because cheap
* Bad, because a city that does nothing is a themed list

### Log flavor only

* Good, because free
* Bad, because the owner asked for systems, not captions
