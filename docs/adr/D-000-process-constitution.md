# D-000 — Process: docs-first main, draft PRs, five-document canon

Status: 🟢 accepted · Phase gate: — · Thread: —

## Context
The repo needed a working agreement before any code: how decisions are made, where docs live, how code enters main.

## Decision
main starts docs-first; every phase arrives as a draft PR reviewed together; the doc canon is five files (README, ROADMAP, ARCHITECTURE, DECISIONS, PRINCIPLES) — see D-028/D-029 for amendments.

## Consequences
Nothing merges undiscussed; documentation cannot pile up; issues carry the living debates.
