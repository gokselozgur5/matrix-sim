# D-015 — Species are data, never classes

Status: 🟡 proposed · Phase gate: v2.5 · Thread: #13

## Context
A big universe must not become a class explosion; sparrow vs pigeon differs in data, not behavior.

## Decision
Proposed: one EnvironmentProgram class + a Species catalog row per kind (Bestiary).

## Consequences
Adding a creature is one line; classes are reserved for behavioral difference.
